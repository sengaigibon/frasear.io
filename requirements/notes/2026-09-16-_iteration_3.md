# Iteration 3.2: Manage saved phrases

Date: 2026-09-18

## Decisions

- A user's fraseario management page lives at `/phrases/manage`.
- The list contains only phrases attached to the authenticated user through `users_phrases` and is paginated.
- Delete means detaching the phrase from the current user; it must not delete the shared phrase record.
- For this iteration, users may edit a phrase attached to them. Duplication handling and the implications of editing shared phrase content are deferred for a later iteration.
- The management view is more compact and functional than search results: edit and delete actions stay inside each phrase item's boundaries, and it does not display "saved by user" metadata.
