### Podman PostgreSQL

``` bash
podman volume create fraseario_pgdata

podman run -d \
  --name fraseario_postgres \
  -e POSTGRES_DB=fraseario \
  -e POSTGRES_USER=fraseario \
  -e POSTGRES_PASSWORD=secret \
  -v fraseario_pgdata:/var/lib/postgresql/data \
  -p 127.0.0.1:5432:5432 \
  docker.io/library/postgres:17-alpine

podman ps
podman logs fraseario_postgres
podman exec -it fraseario_postgres psql -U fraseario -d fraseario -c '\conninfo'
```

## User creation manually

```php artisan tinker```

```` php
App\Models\User::count();
$user = new App\Models\User();
$user->username = 'jkight';
$user->password = Hash::make('password');
$user->first_name = "Javier"; 
$user->last_name = "Caballero"; 
$user->email="email@email.com";
$user->profile = 'Escalador, montañista, naturalista;';
$user->save();
````

```` php
$author = App\Models\Author::create(['name' => 'Anonymous']);

$ph = new App\Models\Phrase();
$ph->body = "Mi primera frase";
$ph->author_id = $author->id;
$ph->save();

$user = App\Models\User::first();
$user->phrases()->attach($ph);
````
