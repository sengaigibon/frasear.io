### Podman PostgreSQL

``podman volume create fraseario_pgdata``

``` bash
podman run -d \
  --name fraseario_postgres \
  -e POSTGRES_DB=fraseario \
  -e POSTGRES_USER=fraseario \
  -e POSTGRES_PASSWORD=secret \
  -v fraseario_pgdata:/var/lib/postgresql/data \
  -p 127.0.0.1:5432:5432 \
  docker.io/library/postgres:17-alpine
```
